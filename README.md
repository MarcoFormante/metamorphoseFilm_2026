# Metamorphose Film

Website for an audiovisual production company, developed for a real client, with a custom admin area that lets the team manage all site content on their own.

🌐 **Live site:** https://metamorphosefilm.com/

> **Note:** this is a commissioned project for a real business. The repository is public for portfolio purposes only; it is not meant to be installed or reused.

## About the project

The company needed a platform to showcase its audiovisual projects, clips and galleries, and to keep the site up to date without depending on a developer for every change.

## What I built

- **Project and clip pages** presenting the company's audiovisual work
- **Dynamic YouTube integration**, so videos are managed from the back office and embedded automatically
- **Image galleries** for each project
- **Custom admin area** where the client can edit every part of the site: projects, clips, galleries and media
- **Interactive front-end** built with Symfony UX and custom Stimulus controllers
- **Reusable UI** built with Twig Components
- **Responsive design**, styled with Sass

## Tech stack

- **Back-end:** PHP, Symfony, Doctrine ORM and migrations
- **Front-end:** Twig, Twig Components, Symfony UX, Stimulus, Sass
- **Assets:** Symfony AssetMapper

## Highlights

- Delivered a complete platform, from the database to the admin, for a real client
- Designed the admin so non-technical users can manage all content autonomously
- Integrated YouTube videos dynamically, driven by data from the back office
